# Topic Resonance —— 把"说不清"变成"就是这个"

## 零、目标与失败标准

**要得到的东西**：一张用户**读得懂**、**卡里有他不知道的东西**、并且能从里面指出"就是这个"的清单。
三样缺一不可：只读得懂是摘要，只有新东西是难懂，只有"就是这个"是他自己的旧话。
不是答案，不是建议，不是初稿，不是选题分析报告。

**一条总判据**：清单是给用户看的，不是给我交代推理过程的。
素材编号、`A/B/C` 代码、`宽/中/窄` 代码、分布统计、流程说明——
这些是**我**用，不是他读的，一律不进交付（§7.2、§十.3）。

**他的反应分三类，处理完全不用**：

| 类 | 他的原话 | 真实情况 | 处理 |
|---|---|---|---|
| **未认领** | "看不懂 / 这写的啥" | **表达失败**：卡片在要求他解码 | §九 第一行 |
| | "都还行 / 有几个不错" | 一张都没中，只是不想否定你 | §九 |
| | "说得挺对 / 很深刻 / 有意思" | **没有增量**：这几张他读之前就知道，只是你说得比他好 | §九 |
| | 不回 | 没认领，也没拒绝 | §九 最后一行 |
| **弱认领** | "我也想这么说" | 他已经指着它了，只是没用编号 | 直接进 §八就在这条上往下做，**不许重出卡** |
| **认领** | 说出编号（"3"／"2 和 5"） | — | §八 |

**一次不中是常态**：一批清单一张都没中有多常见都不奇怪。靠 §九 定向重做，不靠加量。

## 一、什么叫"击中"，以及怎么检验

三条门槛，按顺序：**1.1 认得出**（他读得懂）、**1.2 反不掉**（不是废话）、
**1.5 有增量**（卡里有他不知道的东西）。前两条只管"不失败"，第三条才决定"击中"——
两条都过、第三条不过的清单，读起来就是"都对，都挺好，但没什么用"。

### 1.1 认得出（硬门槛）

没读过我推理过程的人，读一遍就知道"这是在说一件什么事"。

复述不出来，就是表达失败，重写。检验方式两条，第二条最管用：

1. 把这张卡单独摘出来，隔一会儿再读——能不能用自己话复述？
2. 把标题和「怪在哪」拿到 **§1.3 对照表的左列**去比。像左列任何一行，就是还没写完。

**为什么它是硬门槛**：一张卡过不了第一关，用户读到它就翻走了；
一张卡的代价是整份的可信度——后面几张他会带着"这人在说什么"的心态看。

### 1.2 反不掉（质量门槛）

有人能理直气壮地反对它，而且把这句话**反过来写就不成立**。

> 把这句话反过来写一遍。反过来同样成立、同样顺 → 这是描述，不是张力。
> 反过来荒谬或站不住 → 张力成立。

- 通过：`教我的人还在，但教我的路没了` ↔ `教我的路还在，但教我的人没了`（后者荒谬）
- 不通过：`AI 让专家更晚成熟` ↔ `AI 让专家更早成熟`（两边都说得通）

**过不了的时候怎么做**（不是直接删）：回去看「怪在哪」——多数情况是你把落差写成了一个陈述句。
把"两件事对不上"的那两件事都明确摆出来，再跑一次。**改一次仍不过，才删。**

### 1.3 对照表（认得出的执行工具）

左边任何一行对上了，就是还没写完。

| 差（对上就重写） | 好 | 差在哪 |
|---|---|---|
| 被替代的焦虑提前四年到货，可被替代的资格还没到 | 你现在担心的不是被 AI 取代，是你还没资格被它取代：它先到了，你的手艺还没到 | 前者是压缩过的论证，要先解码；后者先给处境再给落差 |
| 括号里的师父 | 唯一还有师父的地方，被你写进了括号 | 前者是索引词，读者得先猜它指什么 |
| 免罪与定性 | 他一边说你不必自责，一边把你的痛苦判给了资本 | 前者是章节名，不是一句话 |
| 往下走：焦虑的利息 / 资格哪年到 / 谁在被替代 | 往下能问：你说"被替代"，指的是这个岗位，还是指"能靠这个吃饭"这件事？ | 前者是关键词拼贴；后者是个真问题 |
| 素材依据：— S27 | 你写的是"（仅仅比我差在不了解一些现实世界的上下文）" | 前者只有我认得出；后者他自己认得出 |
| 怪在哪：AI 让合格变快，让专家变晚（20 字） | 怪在哪：AI 把新手送到"能交付"只用了两个月，把"能扛事"推到五年之后——这两条线第一次分开走（50 字） | 前者是结论；后者把两件事摆出来了，落差他自己能看出来 |

### 1.4 为什么第二条不能当唯一判据

它以前是唯一判据，结果清单被写成了谜语，用户直接看不懂。

原因是**筛选压力会把清单推向谜语**：取反测试奖励"反过来说很荒谬"的句子，
而这类句子天然是格言。反复过筛之后剩下的全是格言，读的人得先补全才懂。

**以后每加一道裁决器，都要同时问一句"它会把输出推向什么形状"。**
只问"它筛掉了什么"、不问"它留下了什么"，就会这样越改越难懂。

### 1.5 有增量（洞察门槛）

前两条都过了，清单仍然可能平——因为**准确的复述也是准确的**。他读完只会点头说"对，就是这样"，
而 §零 把这句话判成失败。

摘要和洞察的区别只有一条：**这张卡里有没有他不知道的东西**。

| 摘要（他只能回"对"） | 有增量（他得停一下） | 增量从哪来 |
|---|---|---|
| 你对 AI 的依赖越来越深，可没人教你怎么判断它对不对 | 你缺的不是判断力，是"错了要赔"的位置：以前错了你担，现在错了模型担，你站在中间传话，两边都不欠你 | 把"能力问题"换成"位置问题"——同一件事换个坐标看 |
| 学徒制在消失，没人带你了 | 学徒制本来就靠低效运转：师父让徒弟干笨活，笨活就是学费。现在笨活被模型接走了，学费没处交，可出师标准一个字没改 | 指出这套制度**成立的前提**，并说明前提已经撤掉 |
| 你的长进变慢了 | 你不是长进慢，是长进第一次没有刻度：以前快慢跟同批人比，现在同批人都快，快就不再是信号 | 换了一个参照系 |

**增量只能来自这五种接点**，其余都是编：

1. **更早的时刻**：这件事以前叫什么、以前怎么办、什么时候开始变的。
2. **成立的前提**：它靠什么才成立，那个东西正在撤掉。
3. **算账的位置**：谁付钱、谁承担、谁签字、谁不在场——把感受落到一个位置上。
4. **同构的别处**：另一个领域里同一形状的事（要说明这是类比，不是证据）。
5. **代价的反面**：他当成问题的那件事，其实是某个解决方案的副作用。

**三条禁令**：

- **深度不是密度。** 不许出现术语、理论人名、"本质上""从哲学上讲"。接点必须用平常话讲完。
- **只许讲结构，不许断言动机。** "因为激励这样设"可以说；"因为你其实怕……"不可以说（同 §三）。
- **类比要标出来。** 写"这跟 X 有点像"，不要写"这就是 X"。

**怎么自检**：把这张卡读给一个只读过素材的人（或自己扮）。他只能回"对"→ 是摘要，回去补接点；
他能追一句"那是不是也意味着 Z？"→ 过了。

**按 §1.4 的规矩先自问一句**：这道筛会把输出推向什么形状？
答：推向"具体、但拐了个弯的平常话"。它一旦开始生产格言或术语，是违反上面三条禁令，
不是这道筛错了——回去改卡，不要撤筛。

## 二、卡片长什么样

三行。**场景在前，落差在后**——顺序不能反，反了他就得先猜后懂。

```
### 3 · 实习做到第四个月，我发现自己主要在验收 AI 写的代码（够聊一次）
**你这边**：你写的是"现在的工作主要就是和 AI 对话"，还有"长进也不大"。
**怪在哪**：你不是不会写，是轮不到你写。它交出来的东西你看得懂、也能改，但它是怎么来的你没参与——
于是"会写"这件事被拆开了：动手的那半留给模型，你留下的是验收那半，而验收不需要手艺。
**往下能问**：你说的"没长进"，是指技术没长，还是指没有一件事能指认是你做的？
```

- **标题**：一句**不需要前情**就能听懂的话，含一个具体名词和一个动作或时刻。
  上面那个标题里有"实习第四个月""验收""AI 写的代码"，没读过素材的人也懂。
  **两条否决**：把具体名词抽掉还完整成立 → 只是话题换皮，重写；
  主语是"我们／人类／行业／时代" → 没人承担，也没人被击中，重写。
  **不要对仗、不要双关**。`被替代的焦虑提前到货`、`免罪与定性` 都是反例：
  前者要先解码，后者是章节名。
- **「你这边」**：一件他做过／说过／写过的事，用他自己的词。
  必须是素材里**真实出现过**的一句话或一个场景；对不上就删这张卡。
  （这是防现编的唯一执行方式——编号证明不了什么，原话才能。）
- **「怪在哪」**：先说清**哪两件事对不上**，再点一句**为什么**（必须落在 §1.5 的五类接点之一）。
  50–90 字是正常长度：压到 20 字会变成谜语，过 120 字就是在写 §八 的内容。
  只许有**一个**落差；第二个落差留到 §八。
  「为什么」那一句只讲结构（前提、位置、时间尺度、激励），不讲他心里的动机。
- **「往下能问」**：一个真问题，能直接拿去问人的那种。写不出就删掉这一行，不要硬凑三个关键词。

**每张卡只讲一件事。** 出现第二个落差就拆成两张，或者删掉弱的那半。

## 三、分组（三组，不合并）

| 组 | 小标题 | 里面放什么 |
|---|---|---|
| A | **最容易认出来的** | 素材支撑最足，我一读就觉得你会点头 |
| B | **你没提，但可能也在意** | 从素材旁边长出来的角度，作用是让你发现"原来我还关心这个" |
| C | **可能会不太舒服** | 你在素材里露出来、又立刻绕开的地方 |

- **A 组里至少有一张**，说的是他不太愿意承认、但听了会点头的事。
  A 组可以温和，但不能整组都是废话——整组温吞，用户就只会回"都还行"。
- **C 组不是可选项**。一组 C 都写不出来，说明只读了字面，没读人。
- **C 组必须落在"他自己"的东西上**。五种来源，优先取前面的：
  ① 他写下的一句；② 他复述／转述过的；③ 他转发、收藏时配的那句；
  ④ 他给这批材料起的标题或文件夹名；⑤ **他这个动作本身**
  （"这几篇是你在同一个文件夹里收着的"就算他的东西）。
  C 组的力度来自"这话／这选择是你自己的"，不要替他说。
- **三组共同的边界**：判断和冒犯都落在处境上，不落在人格上。判据——
  这张卡能不能改写成"你的处境里有 X 在起作用"？只能改写成"你其实是在 Y"，就是指向了人格，重写。

  不合格：`你其实是在害怕被替代。`
  合格：`你怕的不是被替代，是没人愿意为"慢慢变好"这件事付钱。`

**标题后标一个用途词**：`够写一篇` ／ `够聊一次` ／ `当开头`。
它是用户看的**人话**，不算 §十.3 禁止的"分辨率代码"，必须写。

## 四、Phase 0：取材

### 4.1 切片

把材料切成**素材单元**，不要读成"一篇文章"。单元类型：某个具体时刻、他自己用的形容词
（原文保留，不要换同义词）、他已经下的结论、过去与现在的对比、
他提到"但也不是所有人都……"的地方、数字与时间点。

**每条同时标来源**：`[我]` 他自己写的／`[他]` 别人的文章。标记只在内部用，不进交付。

### 4.2 三类信号优先采信

1. **反复出现的词**：出现两次以上的词，通常是他真正的题目所在，即使他自己没强调。
2. **语气变化处**：突然变激烈、突然变短、突然开始自我辩解、突然用玩笑带过。
3. **没被解释的具体细节**：他写了一件很具体的事，却没说明为什么重要。

这三类是**信号，不是结论**。"他没解释"只能推出"这里还有没处理的材料"，
**不能**推出"他有意回避"。要写"你在绕开 XX"，必须能引出原话；引不出，就不要这么写。

### 4.3 素材是别人的文章时

| 来源 | 可以采信 | 不可以采信 |
|---|---|---|
| `[我]` | 4.2 三类全部 | — |
| `[他]` | 作者没解释的细节；他复述／收藏时配的那一句 | 作者的结论（那是作者的题目）；作者的语气（那是作者的情绪） |

有 `[他]` 单元时，问一句：

> "这几篇里哪句话让你停下来了？"

问完就往下走。**他答不上来时不要再问**，改用 §三 的 ③④⑤。
**素材里一个 `[我]` 单元都没有时**（全是别人的文章）：不算素材不足，
用 ③④⑤ 当作 `[我]` 单元照常推进——他挑了这几篇、这样摆放，本身就是他的选择。

### 4.4 素材太薄

**计数判据**：填得进「你这边」的**具体场景**（含语气变化处）少于 3 个 → 算薄。
（形容词、已下的结论、对比、数字都不算场景，堆再多也填不满「你这边」。）

薄的时候先要**一个**具体场景：

> "给我一个具体时刻——最近一次让你有这个感觉，是谁说了什么，或你看到了什么？"

**追问额度见 §九**。§4.3 与 §4.4 同时适用时，**合并成一条消息**，合计不超过 2 个问题。

补完还是薄：**按实有数出 2–4 张，并在开头说一句**"素材只够这几张，要更多得再给点具体的"。
不要注水，也不要为了凑数把同一个意思写成两条。

## 五、Phase 1：产候选（先不要筛）

拿每个具体场景／语气变化／未解释细节，过下面两组问题，**命中就记**。

**A 组（横向错位）——把材料里本来就对不上的两件事摆出来。** 这组保证"站得住"，但只跑到这组，
出来的是摘要：他读之前就知道这些。

1. **期待 vs 现实**：我以为是 A，结果是 B
2. **付出 vs 回报**：我投入最多的那部分，恰好是不再被计价的那部分
3. **公开说法 vs 私下感受**：大家都说 X，我不敢说的是 Y
4. **手段变目的**：本来用来达成目的的东西，变成了目的本身
5. **时间错位**：我按旧时钟走路，新时钟已经换过了
6. **尺度错位**：个人感受被翻译成宏观趋势，于是无处安放
7. **责任错位**：不是任何人的错，但代价由某个具体的人承担
8. **命名失效**：旧词还在用，它指的东西已经变了（"成长""熟练""专家"都属此列）
9. **谁在付钱**：钱从哪来、付给谁、买的是什么
10. **谁在签字**：出了事谁负责；没人负责为什么还能运转
11. **被谁教会**：这项能力的传递路径还在不在

**B 组（纵向结构）——洞察主要从这里出。** 每个被采信的素材单元都要过一遍这组，
至少产一条候选；这组一条没出，说明只在材料表面转。

12. **前提**：这件事靠什么才成立？那个东西还在吗？
13. **来历**：这个说法／做法什么时候出现的，之前拿什么替代它？
14. **记账位置**：收益归谁、代价落谁、谁签字、谁不在场。
15. **时间尺度**：谁按天算、谁按年算；两边不一致时，被牺牲的是哪一边。
16. **反向因果**：不是 A 导致 B，而是 B 让 A 看起来必要。
17. **题解错位**：他当成问题的那件事，其实是某个解决方案的副作用。
18. **不可逆点**：哪一步之后回不去了；回不去之后，旧评价标准为什么还在用。
19. **同构**：别的领域里同一形状的事（标明这是类比，不是证据）。

**什么时候停**（池子上限，不是产出承诺）：

- 按 7 张打算 → 候选到 **20 条上下**就停。
- 素材薄（§4.4、按 2–4 张打算）→ 候选到 **10 条左右**就停。

继续加发只会让池子变长，不会让它变好。

## 六、Phase 2：筛（产和筛必须分开）

按顺序过，每条落一个去处，不许"感觉不错"就留下：

1. **先杀重复**：两条候选互换标题还成立 → 合并成一条，留素材支撑多的那版。
2. **认得出**：说不出"这是在说一件什么事" → 重写或删（§1.1、§1.3）。
3. **反不掉**：反过来也成立 → 按 §1.2 改一次「怪在哪」，仍不过才删。
4. **能写成三行**：这条能不能填出「你这边／怪在哪」？
   写出来发空、只能写成一句格言的 → 删。**这一步最容易漏，格言是筛出来的，不是想出来的。**
5. **有增量**：按 §1.5 自检。只能被回"对"的卡，回 §五 B 组补接点一次；补完仍只有复述 → 删。
   这一步和上一步管的是两件不同的事：第 4 步问"写得出来吗"，这一步问"写出来有没有新东西"。
6. **最后定 C 组**：从剩的一堆里挑出"他写过原话、紧接着又绕开了"的那 1–2 条。
   C 组先占位，别让它被剩余额度挤成填充物。
7. **数一遍，按池子状态分岔**（这一步只判"够不够"，不判"好不好"）：
   - 活下来 ≥6 张 → 进 §七。
   - 活下来不足 6 张、**池子还没到 §五 的上限** → 回 §五 补发一轮，
     只补你还没过的那几个发生器，补完回来重新筛。
   - 活下来不足 6 张、**池子已经到上限** → 这批素材最多就撑这几张。
     按实有数发，开头写明（§7.1）。不要为了凑 6 张把已删的卡捡回来。

---

## 七、Phase 3：出卡与交付

### 7.1 张数（护栏，不是规格）

- 常态 **6–8 张**，每组不超过 4 张，**C 组至少 1 张**。
- 整份里**至少 1 张是「重估型」**：把材料里被当成问题的事，重新看成某个解决方案的产物（§五 16／17）。
- 整份里**至少 1 张跨出这批材料**（§五 12／13／14／19），并用平常话点明那是接点、不是事实。
  这两条可以由同一张卡同时满足；一条都没有时不许交付——那说明整份还停在摘要层。
- 真正的判据不是数字，是：**整份清单能一口气读完，不用往回翻。**
  卡片现在每张三行，8 张约等于以前 9–10 张的阅读量——上限按这个换算，不要再加。
- 少了就说一句，不注水：`只写到这几张，再多就是凑数`。
  **说出来的少发不算失败，不说才失败**——但少发只有在 §六 第 7 步走到"池子已满"时才算正常；
  池子没满就少发，是偷懒。

### 7.2 交付形态

在对话里出，不写文件（他说"存下来／给我个文件"才写）。

**开头最多一句**，说他这批材料在说什么——不评价、不推荐、不预告分组：

> "这三篇一直在说同一件事：你会多少，和你值多少钱，本来是绑在一起的，现在松开了。"

**不许有流程说明**（"我已 §4.3 处理……"这类），**不许有内部记号**（§十.3）。
用途（`够聊一次` 等）是给用户看的，不算内部记号。

**结尾一句话**说明怎么用：`指个编号就行，也可以说"3 但方向不对"或"都太笼统"。`

### 7.3 姿态

- 只给卡，不给建议，不劝进，**不额外排序**。不说"建议你先看第 3 张"。
- **A 组在 B 前是"离素材更近"，不是"更好"。**
- 不解释"为什么我认为这张好"——那会把他的指认变成对我的评价。
  卡片里的「你这边」是证据字段，它指向他的材料，不指向我的品味。
- 他说"先给我两三张"：照给。先给 **C 组一张 + A 组一张**（这两张最能判断方向对不对）。
  这是交付节奏，不是推荐顺序。

## 八、Phase 4：勾选之后

他勾 1–3 个（或说"2 和 5，但我要更窄的"，或说"我也想这么说"）→ **先查冲突，再收敛**。

**被勾的几张互相矛盾时**（一张说"学徒制塌了"、一张说"学徒制从来不存在"），
先指出它们不能同时成立、冲突在哪一处，让他选锚点，再动笔。不要硬拼成一个自相矛盾的主题树。

```
## 主命题
一句话（从被勾的卡里提炼，可以不同意原卡）

## 为什么值得谈
3 条，每条落到他素材里的一句话

## 子问题（3–5 个，按回答顺序排）
1. …
2. …
3. …

## 反方最强的一击
针对上面那句主命题来反驳（写得比他能想到的更强）

## 下一步
- 要写 → 进入写作；主命题原样传过去，不许改写
- 要谈 → 按子问题顺序逐条展开；当前环境有专门的深挖流程就交给它，没有就自己按顺序展开
- 要查 → 指出哪一条需要在现实中验证
```

**注意**：卡片上没有"命题"字段，所以「反方最强的一击」针对的是**这一节刚写出的主命题**，
不是卡上的东西。主命题写偏了，这一击就打空——所以先确认主命题，再写反方。

**不要在这一步扩写正文。** 他要的是方向，不是初稿；给了初稿他就没得选了。

**交接只在他明确说"想写／想聊／想查"时发生**；没说就停在主题树。

**回答"哪个方向最值得写"的合法方式**：不说哪个好，只标两类信息——
哪几条有他自己的原话直接支撑（＝最不容易写空的），
哪几条是他自己绕开的（＝最可能有话没说的）。这是证据标注，不是排序。

## 九、Phase 5：不中之后

**不要重跑一遍加量。** 先认是哪一种：

| 他说的 | 真实问题 | 处理 |
|---|---|---|
| **"看不懂 / 这写的啥"** | **表达失败**：卡片在要求他解码 | 不换用途词、不加量。回 §二 重写：每张卡补出「你这边」，标题换成不需要前情的一句话，「怪在哪」摊开成平常话。改完自己先读一遍 |
| "都太笼统 / 太抽象 / 太大" | **用途词**错配：给的是"够写一篇"，他要"能当开头" | 全部换成更具体的用途词，标题落到一件事的具体时刻 |
| "不是这个感觉" | 情绪没被写进卡 | 回 §4.2 第 2 类，找语气变化处重做 |
| "对，但这不是我想说的" | 他真正关心的在更上游或更下游 | 问"你希望讨论完之后，手上多出什么？"按答案上移或下移一层 |
| "有点意思，但不够狠" | 落差成立，但你说好话的部分太多了 | **只改他勾的那张及其同组**：「怪在哪」里替他开脱的那半句删掉，只留他不愿承认的那半。不要把所有卡都加辣 |
| **"对，但没什么新东西／不够深／就这样吧"** | **停在摘要层**：卡里全是他本来就知道的 | 不加辣、不加量。回 §1.5 给这几张补接点，优先 13（来历）与 12（前提）——这两类最容易被漏掉 |
| **"都还行／有几个不错／说得挺对／很深刻／很有意思"** | 一张都没中，只是不想否定你 | 先按上一行处理：整份补接点、且只重做 C 组与 A 组各一张；不要原样加量 |
| "我也想这么说" | 已经是弱认领 | 直接进 §八，不重出（§零） |
| 只勾一张、不表态 | 已认领，只是不想被追问 | 直接进 §八，只做这一条，不主动延伸 |
| 勾了 2–3 张但互相矛盾 | 撞到两个不同面 | 按 §八 冲突处理，先让他选锚点 |
| 完全不回应 | 还没认领，也不打算继续 | 止损：不重出，问"要窄一点，还是换一批素材？"。问一次不回就停在这里 |

**只重跑受影响的组，不要全盘重来**——全盘重来会让他觉得自己的指认没产生作用。
重出时不要重复已经出现过的标题。

**重出上限**：同一张卡最多重写一次；整份清单最多重出一次。
第二次仍不中 → 不要再改，直接说"这批素材我读不出更准的东西，换一批或补两段具体经历"。

### 追问额度（全流程唯一口径）

**出卡前一条消息、出卡后一条消息，每次不超过 2 个问题。用掉就按现有信息往下做。**

| 时机 | 额度 | 说明 |
|---|---|---|
| 出卡前 | 1 条消息，≤2 问 | §4.3 与 §4.4 同时适用时合并起来问，选哪两个由你定 |
| 出卡后 | 1 条消息，≤2 问 | 上表里**只挑一行**执行；如果两种情形都像（例如"不是这个感觉"又"不够狠"），只问最可能的那一个 |

## 十、硬规则（违反任一条即算这个 skill 失败）

1. **不评判人格**：判断和冒犯都指向处境，不指向人格或选择（§三）。
2. **不给结论**：不产出"所以你应该……"。
3. **交付里不出现内部记号**：素材编号、`A/B/C` 代码、`宽/中/窄` 代码、
   分布统计、流程说明。用途词是给用户看的，不在此列（§三）。
4. **每张卡对得上原话**：「你这边」必须是素材里真实出现过的一件事；对不上，删卡。
   C 组例外：可以用 §三 的 ③④⑤ 三种替代来源。
5. **追问总共两条消息**：出卡前一条、出卡后一条，各最多 2 个问题（§九）。
6. **少发要说，凑数更糟**：少发只在 §六 第 7 步走到"池子已满"时才允许；
   无论哪种情况，都要在开头说明（§7.1）。
7. **每张卡必须有增量**：卡里必须落一个 §1.5 的五类接点之一；只能被回"对，就是这样"的卡不许交付。

## 十一、交付前自检

> **交付前必须完整读完 `references/checklist.md`，逐项过，不跳。**
> 范围：首批、分批的每一批、§九 重出后的每一批。
> **Phase 0–2 期间不要打开**：里面挂着张数上限与原话核对，发散期读到会让人提前自我审查。
> （认得出的对照表已经搬到 §1.3，所以筛选阶段不再需要这个文件。）
>
> 清单正文只维护在那个文件里，本文件不留副本。
