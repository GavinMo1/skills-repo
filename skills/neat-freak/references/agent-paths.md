# 环境规则、记忆与安装来源

**读取时机：** 需要确认某文件是否真被加载、记忆能否写入、同名 skill 是否为真身时读；轻量流程不读。

路径和产品行为会变化；下列名称用于查找，不证明文件存在、会被加载或可以修改。

## 先区分文件类型

| 类型 | 核对重点 |
|---|---|
| 人工维护规则 | 当前环境支持的文件名、作用域、加载顺序和覆盖规则 |
| 可编辑记忆 | 用户授权、平台允许的写入入口、与项目文档的分工 |
| 机器生成历史或索引 | 生成来源和允许的控制入口；没有明确许可则不直接编辑 |

`MEMORY.md` 只是名称，不能据此推断语义。无法归类的文件先只读，标记待确认；不直接认定它是机器生成。

## 发现实际规则链

1. 确认当前环境、项目根和工作目录。
2. 从环境已提供的指令和配置确认全局、上级、项目及路径规则。
3. 查找可能的规则文件，但只将有加载依据的文件认定为生效规则。
4. 记录同目录覆盖、导入、软链和条件规则。读取符号链接前确认目标仍在允许读取的范围。
5. 无法确认加载时，报告“文件存在，加载未核实”；不要给出完整加载结论。

常见线索：

- Claude 系环境：CLAUDE.md、CLAUDE.local.md、.claude/rules/ 和环境提供的记忆入口。
- Codex 系环境：AGENTS.md、AGENTS.override.md、配置中的替代文件名，以及当前环境提供的 skill 目录。
- 其他环境：原生规则目录、项目设置和官方加载诊断。

这些线索不是完整路径清单，也不是跨产品兼容保证。不要因为当前环境读取一种文件，就给所有项目创建同名文件。

## 记忆处理

先读本环境的记忆说明，再确定是否有权更新。只有环境明确支持时才使用其命令、设置或更新输入；不要猜测 `/memory`、`/memories` 等命令可用。

对机器生成文件，优先使用其规定输入或控制入口。找不到允许的方式时保留文件并报告限制。文件尺寸、截断、索引和压缩规则必须来自本环境依据，不沿用其他产品的数字。

## 同名安装与规则同源

在任务需要时检查实际安装目录和解析后的路径。常见形态包括独立副本、软链、导入和生成镜像。

- 只编辑授权范围内的权威来源；先确认权威，不默认某个文件永远是真身。
- 独立副本不会因修改一份而自动同步。
- 同源声明存在时，核对目标、内容和实际加载；只确认路径相同不等于加载正确。
- 发现多个环境目录不等于它们都在使用；不自动扩大审计。
- 不支持软链时，保留项目声明的导入或生成方式，不为统一形式改造项目。

## 体量与降级

只有任务需要时才查环境的文档体量限制。报告实际大小、已确认限制及读取风险；未知上限不编造百分比告警。

缺少加载诊断或官方依据时，仍可完成授权范围内的内容核对，但必须保留加载状态未核实这一限制。不支持技能发现的环境可按用户要求手动读取说明；这不代表该环境已正式安装或完整支持本 skill。
