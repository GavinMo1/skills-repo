# 出卡前自检

> **出卡前必须完整读完本文件，逐项过，不跳。** 任何一项不过就回改，改完再从头过一遍。
> 主文件 §十一 只留指针，清单正文唯一维护在这里。
>
> 判定分工：**取反测试**判"是不是张力"（主文件 §1.4）；
> **五条禁令**判"是不是这个人的主题"（`references/naming.md`）；本文件判"整份清单能不能被指认"。

---

## 一、逐卡过（十项）

- [ ] 每张卡的「素材依据」都指向真实存在的编号（S1…Sn），不是现编的？
- [ ] 每张卡的**「张力」行**跑过取反测试（主文件 §1.4）？反过来也成立的重写。
- [ ] 每张卡跑过**五条禁令**（`references/naming.md`）？命中一条就重写。
- [ ] 单卡 ≤6 行、张力与命题各 ≤32 字，且**卡内没有"因为／所以／然而／但是"**？
      出现连接词说明你在卡里写论证，论证属于 Phase 4。
- [ ] 每张卡都能改写成"你的处境里有 X 在起作用"？只能改写成"你其实是在 Y"的，指向了人格，重写。
- [ ] 若卡片写了"你在回避／你不愿承认"，能指出素材里的原话位置（S 几）？指不出就降级为"这里有个你没说清的地方"。
- [ ] 「击中谁」全部是处境限定，没有一个"很多人 / 职场人 / 年轻人"？
- [ ] 素材含他人文章时，「击中谁」写的是**用户与那篇文章的关系处境**，不是作者的读者群？

## 二、整份清单过（六项）

- [ ] C 组 ≥1 张，且每张都指出了素材里的哪句话暴露了它？
- [ ] 冒犯度按组分档（A=1 格、B=0 格、C=2 格），不是每张都在刺人？
- [ ] 张数在 7–10（或按主文件 §3.5 降级）？**任何偏离都没有静默发生**——清单开头有一行声明？
- [ ] 分辨率三档不全缺席，组尾标了分布；缺档写的是"素材不足，未凑"而不是硬凑一张？
- [ ] 通篇没有建议、没有排序、没有"我觉得这张最好"？
- [ ] 结尾有那句用法说明（`勾编号即可，也可以说"3 但方向不对"或"都太抽象"。`）？

## 三、好坏对照（校准用）

| 差 | 好 | 差在哪 |
|---|---|---|
| AI 与就业 | 手艺的价格死了，手艺没死 | 前者是话题，后者是张力 |
| 论 AI 时代的劳动异化 | 我卖掉的不是劳动，是我最想干的那八小时 | 前者是术语墙，后者有具体名词与落差 |
| 我们应该拥抱变化 | 教我的人还在，但教我的路没了 | 前者是口号，后者可辩论且带痛 |
| 技术、资本与主体性 | 谁在为"我还能长成专家"这件事付钱 | 前者三个概念连缀，后者指名了承担者 |
| AI 会让专家更晚成熟 | AI 让合格变快，让专家变晚——这两个速度差，就是学徒制塌掉的地方 | 前者是裸结论（取反也成立），后者钉住了机制 |
