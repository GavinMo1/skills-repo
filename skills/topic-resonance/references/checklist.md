# 交付前自检

> **交付前必须完整读完本文件，逐项过，不跳。** 范围：首批清单、分批交付的每一批、
> §九 重出后的每一批。任何一项不过就回改，改完从头再跑一遍。
>
> **Phase 0–2 期间不要打开**：里面的张数上限与原话核对会让候选在发散期被提前筛掉。
> （"认得出"的对照表在主文件 §1.3，"有增量"的判据在 §1.5——筛选阶段用那两节，不用本文件。）
> 主文件 §十一 只留指针，清单正文唯一维护在这里。

---

## 一、先把清单当读者读一遍（顺序不能换）

这三项过不了，后面全部白做——它们判的不是内容好不好，是**他能不能读懂**。

- [ ] 从第一行读到最后一行，有没有哪一行要停下来想"这是什么意思"？有，就重写那一行。
- [ ] 每个标题拿到一个没读过素材的人面前，他会不会问"这是什么意思"？
      标题里有一个具体名词、一个动作或时刻（`实习第四个月`、`验收 AI 写的代码`）吗？
      是不是对仗或双关？——是，重写成平常话。
- [ ] 每句「怪在哪」都反过来写过一遍？反过来还成立 → 回 §1.2 改一次，仍不过就删。

## 二、增量（这一节决定"击中"，不许跳）

能读懂、也反驳不掉，仍然可能是**摘要**——他读之前就知道这些。逐张问：

- [ ] 这张卡的「怪在哪」指得出**哪一类接点**（§1.5 五种之一）？指不出的，回 §五 B 组补一次；补不上就删卡。
- [ ] 做过"只能回对"自检？把卡读给一个只读过素材的人，他只能回"对，就是这样"→ 还是摘要；
      他能追一句"那是不是也意味着 Z？"→ 过了。
- [ ] 全篇没有术语、理论人名、"本质上""从哲学上讲"？一个都不许有。
- [ ] 没有格言？判据：这句话自己就完整、不需要任何前情，读起来像座右铭 → 回 §1.5 换成带具体事的说法。
- [ ] 「为什么」那一句只讲结构（前提、位置、时间尺度、激励），没有断言他心里的动机？
- [ ] 类比都写了"这跟 X 有点像"，没有写成"这就是 X"？

## 三、逐卡过

- [ ] 「你这边」对得上素材里真实出现过的一句话？对不上，删卡（§十.4）。
- [ ] 「怪在哪」：先说清哪两件事对不上、再点一句为什么，50–90 字？
      短到 20 字（谜语）或长到 120 字以上（在写 §八 的内容）都要改。
- [ ] 「怪在哪」只讲了一个落差？（讲了两层以上 → 拆卡，或挪到 §八 收敛阶段）
- [ ] 「往下能问」是个真问题，不是三个关键词的拼贴？写不出就删掉这一行。
- [ ] 能改写成"你的处境里有 X 在起作用"？只能写成"你其实是在 Y"的，指向了人格，重写。
- [ ] 标题后标了用途词：`够写一篇`／`够聊一次`／`当开头`？
- [ ] 这是 C 组的卡吗？是 → 落在 §三 的 ①⑤ 五种来源之一（①自己的话 ②复述过的
      ③转发时配的 ④自己起的标题 ⑤收集这个动作本身）。

## 四、整份过

- [ ] **A 组里至少有一张**说的是他不太愿意承认、但会点头的事？（整组温吞 → 只回"都还行"）
- [ ] **C 组至少有 1 张**。
- [ ] **至少有 1 张「重估型」**：把被当成问题的事，重新看成某个解决方案的产物（§五 16／17）？
- [ ] **至少有 1 张跨出这批材料**（§五 12／13／14／19），并且用平常话点明那是接点、不是事实？
- [ ] 6–8 张、每组不超过 4 张？
- [ ] 少发了的话，是 §六 第 7 步走到"池子已满"才少的吗？开头说了一句吗？
      （池子没满就少发 = 偷懒，回去补候选）
- [ ] 能一口气读完、不用往回翻？
- [ ] 开头最多一句，说是"这批材料在说什么"？没有流程说明、没有内部记号（§十.3）？
- [ ] 通篇没有建议、没有排序、没有"我觉得这张最好"？
- [ ] 结尾有那句用法说明？
