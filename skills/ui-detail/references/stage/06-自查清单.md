# 06 · 交付自查清单

> **适用**：交付前要一条条走验收路径、按对象抽查、并写下可追溯的记录时。
> **不适用**：还在设计或实现阶段、结论未成形时（此时读对应阶段文件，不要拿清单代替动手）。
> **读完能判定**：哪些路径已走、哪些没走；每个对象的通过标准是否达成；记录是否可追溯；哪些情况必须写进例外而不是默认算通过。

用法：准备真实内容（长标题、超长项目名、空字段、无权限对象、失败响应、大数据量），在明暗两种主题下各走一遍。每一条要么打勾，要么在报告里写成例外并给出理由——两者都没有，视为没做。

细则与理由：[08 落地与验收](../detail/08-落地与验收.md))，其余条目来自 [01](../detail/01-浮层.md))–[17](../detail/17-拖拽与排序.md))。

## 主路径

准备：短标题、超长标题、空项目、无权限项目、失败响应、大量列表数据。

- [ ] 进入项目列表：加载与失败有区别，图片与字体加载时无明显意外跳动。
- [ ] 搜索不存在的名称：提示无结果，可清除筛选，输入没有丢失。
- [ ] 仅用键盘打开项目：名称清楚、焦点可见、顺序符合任务。
- [ ] 编辑并制造校验错误：错误有文字说明、能定位，修正后及时更新。
- [ ] 打开日期选择器：子浮层可操作，关闭后焦点回到正确位置。
- [ ] 慢网下连续提交：立即显示保存状态，没有重复创建。
- [ ] 保存失败再重试：保留输入，说明影响，恢复后可继续。
- [ ] 有未保存修改时关闭：不会因误点丢失内容，放弃后焦点合理返回。
- [ ] 切换明暗主题：文字、控件、焦点与状态的必要对比均检查，图片没有被无差别改色。
- [ ] 窄屏、200% 放大与长文案：主要内容可重排，重要文本和操作不被裁掉。
- [ ] 放大到 200%、1x 与 2x DPR：图标、按钮文字、圆形与斜角元素没有肉眼可辨的偏移，圆角嵌套处厚薄均匀。
- [ ] 减少动效与强制颜色模式：交互仍能完成，必要边界依然可见。
- [ ] 使用读屏器：能听懂字段名称、错误和保存结果，没有重复或过量播报。

截图检查间距与视觉层次，键盘检查焦点路线，读屏器检查名称与动态反馈，浏览器工具检查性能与对比度。它们回答的问题不同，要一起用。

## 按对象抽查

用真实数据，不要用占位文本穿过全部行。

| 对象 | 操作与条件 | 通过标准 |
|---|---|---|
| 结构与排版 | 放大 200%、1x/2x DPR、中英混排、圆形与三角图标、描边与阴影并排 | 区块收敛到少数几条对齐线，墨迹也齐；偏移有注释可依，热区与焦点环没有被缩小 |
| 浮层 | 只用键盘打开、切换字段、展开子面板、关闭 | 焦点进入内部、循环、关闭后回到触发元素；子面板不被判为外部点击 |
| 浮层 | 快速开关、进入中按 Esc、关闭中重开、滚动祖先、改窗口大小、软键盘 | 旧回调不破坏新状态；定位跟随、不被边缘裁掉；动效关闭后流程照常 |
| 输入框 | 聚焦、失焦、切换错误态 | 边框变化不挤文字，焦点即时可辨，错误不遮挡内容 |
| 输入框 | 有初始值、自动填充、长标签、放大文字 | 标签不覆盖内容，名称与值都可读 |
| 输入框 | 中间插入、选中替换、粘贴、撤销、中文选词 | 字与光标跟手，不丢选区，Enter 不误提交 |
| 搜索 | 快速输入、组合输入、清空、旧请求晚返回 | 输入立即更新，旧结果不覆盖新查询，失败不伪装成无结果 |
| 多行输入 | 粘贴长文、删除、达到最大高度 | 高度与滚动合理，当前编辑位置可见 |
| 平滑光标（若启用） | 高频输入、跨行、选区、IME、字体与宽度变化、内部滚动 | 装饰光标跟随真实插入点；测量失效立即恢复原生表现 |
| 平滑光标（若启用） | 首次聚焦、失焦、空闲、减少动效、强制颜色模式 | 不从原点滑入，输入时无额外闪断，降级行为明确，测量成本有性能记录 |
| 按钮 | 慢请求、快速连续激活、不同长度文案 | 尺寸稳定、状态有说明、焦点合理、无重复业务操作 |
| 选择器 | 键盘选项、触屏滚动、点选、Esc、Tab | 不因失焦吞掉选择，不误选，退出路线明确 |
| 数据列表 | 排序、跨页选择、筛选、删除、详情返回 | 选择按对象保存，范围明确，分页、滚动与焦点按约定恢复 |
| 数据列表 | 批量部分失败、加载更多失败、末页删空 | 逐项结果可追溯，只重试失败项，页码与空态重新计算正确 |
| 上传 | 一份过大、一份断网、一份成功、一份解析失败 | 每项状态可追溯；成功项不因其它项失败丢失；只重试失败项 |
| 上传 | 取消传输、同名文件、重复选择同一文件、关闭再返回 | 三个动作的文案与后果分开；不产生重复附件；返回后状态仍准确 |
| 保存与草稿 | 先存 A 再改 B、A 晚返回、随后保存 B | 已确认区为 A、当前编辑区为 B 且仍未保存；不把 B 标为已保存 |
| 保存与草稿 | 断网、恢复、切对象、双标签页 | 内容保留、冲突有说明、A 的回包不写进 B |
| 日期与时间 | 键入有效与无效日期、翻月不选、清空再提交、跨年与闰日 | 不静默改值，禁日有原因，键盘可导航 |
| 日期与时间 | 同一纯日期在不同时区显示、会议时区与夏令时边界 | 纯日期不差一天，时刻显示正确时区 |
| 拖拽与排序 | 拖拽与"移动到"各走一次；空列、无权限列、视口边缘、Esc、放回原位、保存失败 | 位置可预期，取消不提交，失败可恢复，触屏滚动未被破坏 |

## 记录

- 记录"哪个操作、什么条件、观察到什么、改了哪里"，不写"已优化体验"。
- 动效的毫秒数不是验收结论：看短过渡是否帮助识别变化、有无打断输入、有无增加等待。
- 模拟请求不涉及真实服务端，不能据此宣称生产幂等、离线恢复与版本冲突已通过。
- 未覆盖的路径逐条写进报告，不要省略。
