# 读者试读

检查目标读者沿指定阅读路径，是否能获得阅读目标所需的理解。关注概念、关系和行动依据如何逐步形成，不只检查知识是否齐全。修改以降低理解阻力为目标，不默认增加内容。

模拟读者意见不等于真实用户测试。独立上下文可以减少作者结论的影响，但不能让模型忘记已有知识。判断应联系读者画像、前文提供的信息和具体位置，不依赖统一篇幅、章节模板或分数。

## 建立读者与任务

从用户请求和上下文提取阅读目的、已有基础、期望深度、明确不需要的内容、材料范围与入口。不要把某次用户的技术栈或偏好固化为默认值。

画像缺失时，根据材料声明的受众作简短假设并继续。不同画像会显著改变判断时，询问影响分析的缺口，不编造职业、能力、耐心或喜好。

默认只读并汇报。用户已授权修改时，按授权范围修改并复读，不重复请求确认。除非用户要求留档，不向材料目录添加评审报告、评分表等过程文件。

## 派发独立读者

派发前读取[读者任务要求](references/reader-task.md)，将相关要求与材料位置、必要访问方式、画像和阅读目标交给一个独立子 Agent。默认不继承历史，不传作者推理、旧评审结论、预期缺陷或想要的评分。子 Agent 只读，不修改，也不继续派发。

材料包含评审报告或修订记录时，先读正文，再按需要查过程记录。若已接触旧结论，说明可能的影响。工具无法提供独立上下文时，说明限制；无法调用子 Agent 时改为单 Agent 模拟试读，不声称独立评审。

一个读者沿目标所需路径阅读，不用并行拆章代替完整阅读体验。用户要求多种画像时，可以分别派发读者，并区分各画像的结论。

大材料先选择与阅读目标相关的路径，说明选择原因。分别记录完整阅读、局部查阅与未读部分。局部阅读只支持相应范围的判断；未检查相关衔接时，不评价整套资料的章节顺序。

## 汇总与判断

收到意见后，回查高影响发现对应的原文。区分材料观察、模拟判断和待用户确认的问题，不把模拟读者声称困惑当作充分证据。

读者发生误读时，先检查原因：

- 原文已经明确说明，但读者漏看：判断位置、指代或呈现是否使信息容易被错过。
- 原文允许多种合理解释：保留歧义及其可能影响。
- 读者使用了画像不具备的知识，或忽略画像已有基础：修正模拟判断。
- 意见与原文不符且无法由表达诱发：撤回该项，并说明影响结论的修正。

不要为了维护作者结论而删除有依据的困惑，也不要把每次漏读都归咎材料。合并共同原因，保留独立的重要障碍及有价值的分歧。

报告总体判断、实际阅读路径与覆盖、影响阅读目标的问题及建议、应保持的解释与节奏，以及核验限制。按影响排序，不凑问题数，也不为追求“少量”省略重要问题。位置优先使用可点击文件链接。

说明哪些是模拟读者意见，哪些是主 Agent 回查后的判断。不声称用户本人已经有同样体验。技术疑点未核验时，不直接定性为事实错误。

## 修改与复读

获得修改授权后，选择足以解决障碍且总体阅读负担合理的动作：补推导、移动内容、删除重复、合并、换例子或保持原样。局部补丁不能解决结构问题时，可以重组授权范围内的内容；不以改动字数最少为目标。需要超出授权范围时，说明建议与限制，不自行扩改。

先帮助读者沿主要阅读路径形成理解，再展开必要分支。适用条件和关键限制仍靠近对应结论，不能为流畅移到容易忽略的位置。修改后检查相邻段落、前置关系和交叉引用。

按复读目的与改动影响选择方式：

- 用户要求重新体验整体材料：使用新读者，不给旧结论。
- 用户要求检查指定问题：可以复用原读者，提供待验证问题，标为定向复查。
- 术语或局部例子修正：检查该处与相关上下文。
- 概念移动或章节重排：从受影响的前置位置沿路径重读，检查后续依赖。
- 受众或阅读目标改变：重新建立画像，再按新目标试读。

每轮以用户请求范围为终点，不自动无限评审。只剩风格偏好或超出目标的扩展时，如实报告；无法完成必要复读时，说明未验证范围，不宣称修改已解决全部问题。
