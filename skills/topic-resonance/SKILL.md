# Topic Resonance —— 把"说不清"变成"就是这个"

## 零、目标与成功标准

**这个 skill 要帮用户得到什么**：一张**能被指认的张力清单**。
不是答案，不是建议，不是初稿，不是"选题分析报告"。

**成功标准（唯一口径）**：用户从中勾出 1–3 个，或明确说出"我要更窄的／更狠的"。
**产出一批漂亮但没人认领的主题，等于失败。**

两种回复不算成功，按失败处理（处理方法见 §九）：
- "都还行 / 有几个不错"——一张都没击中，只是不想否定你。
- 沉默——没认领，也没拒绝。

**素材门槛**：素材只有一句结论、没有任何具体场景时，先补素材再走本流程（见 §3.5）。

**遇到不适用本流程的输入时怎么办**：见 §3.8 的中止条件。

## 一、"击中"的可操作定义

### 1.1 基础条件（每一张卡都必须满足）

1. **命名了已有经验**：用户经历过、但没找到词去说的那件事，被一句话说出来了。
2. **可辩论**：有人能理直气壮地反对它。不能被反对的命题不是命题，是共识或口号。

### 1.2 冒犯度按组分档（是每组的下限配比，不是逐卡门槛）

"带一点冒犯"由**整组**承担，不要求每张卡都刺人——每张都刺人，清单会像在审讯用户：

| 组别 | 冒犯度 | 要求 |
|---|---|---|
| A 组 | 1 格 | 至少一半的卡指出一个他不愿意承认的事实，但不指控他 |
| B 组 | 0 格 | 可以不带冒犯，但必须是"他没意识到自己关心"的角度 |
| C 组 | 2 格 | 每张都必须是他在素材里露出、又立刻绕开的部分 |

**A 组与 C 组的判别式**（两组都会说"你不愿承认"，靠这一条分开）：

- 只能推到「你的处境里有 X 在起作用」→ **A 组**，不要求指认素材原话。
- 必须能点出**他在素材里绕开的那句原话**（S 几）→ **C 组**。
- 指不出原话时按顺序处理：①措辞降级为"这里有个你没说清的地方"（见 §3.3）；
  ②归入 **A 组**，不要在 C 组留下一张无出处的卡。

**只让人舒服的主题不会击中，只会被点赞**；但每张都刺人，用户会关门。

### 1.3 反向信号（出现即不算命中）

"说得挺对"（正确但无关）、"很深刻"（抽象）、"有意思"（还没落到他身上）、
"我也想这么说"（这是借来的）。

用户回复落在这一组里时，**按没认领处理**：走 §九，不当作勾选，也不要因为"他说还不错"就进 §八。

### 1.4 "咯噔"的可操作替身：取反测试

"咯噔"是目标，不是判据——它没法自检。出卡前对每句张力跑一遍**取反测试**：

> 把这句话反过来写一遍。如果反过来的版本同样成立、同样顺，说明落差没被钉住，
> 这句话只是描述，不是张力；如果反过来荒谬或站不住，张力成立。

- 通过：`教我的人还在，但教我的路没了` ↔ `教我的路还在，但教我的人没了`（后者荒谬）
- 不通过：`AI 让专家更晚成熟` ↔ `AI 让专家更早成熟`（两边都说得通 = 只是描述）

**两条执行细则**：

1. **执行对象只有卡片的「张力」行**（§7.1）。话题、命题、§二 的分辨率示例都不跑这一测试——
   宽度示例多半是框架句，反过来说得通是正常的。
2. **它判的是"有没有钉住落差"，不是话题好坏。** 同一个话题，裸写不过、加机制就过：
   - 不过：`AI 让专家更晚成熟`（裸结论，反过来说也顺）
   - 过：`AI 让合格变快，让专家变晚——这两个速度差，就是学徒制塌掉的地方`（反过来说没人会这么讲，
     且钉住了"两个速度"这个机制）

   **注意上线**：这一句约 33 字，只作论证示范；真放进卡里要压到 §7.1 的 32 字以内。

## 二、三层输出，必须分清

| 层 | 形态 | 例子 | 作用 |
|---|---|---|---|
| **话题** topic | 一个名词域 | AI 与学徒制 | 太大，不能击中，只用于导航 |
| **张力** tension | 一句落差 | 教我的人还在，但教我的路没了 | **击中发生在这里** |
| **命题** thesis | 一句可反驳的判断 | AI 没有夺走工作，它夺走了"绕远路"这条成长通道 | 拿去做讨论/写作 |

**铁律：用户报"说不清"时，九成是拿到了话题、缺张力。** 所以每次输出的主件必须是张力，
话题只作为分组标签出现，命题作为张力的下游。

**分辨率三档**（同一内容可写成三种宽度；用户"说不清"常常是分辨率错配，不是没题目）：

- **宽**（可支撑一篇文章 / 一次完整讨论）：`当手艺的价格和手艺的价值脱钩`
- **中**（可支撑一次深度探索）：`AI 让合格变快，让专家变晚——这两个速度差，就是学徒制塌掉的地方`
- **窄**（一句话就能击中，适合做标题或开场）：`我学会这门手艺的路，被修成了高速`

上面三句**只示范宽度，不示范"是不是张力"**——卡片级的张力判定只走 §1.4。
中档那句约 33 字，作宽度示范用；真写进卡要压到 §7.1 的 32 字内。

出卡时每张都标分辨率，并保证 A+B 组合起来**至少覆盖三档中的两档，且宽 ≥1、窄 ≥1**；
第三档素材确实没有时允许缺，但必须在组尾分布行注明（分配细则见 §7.2；
降级态见 §7.2——宽或窄占一档即可）。

## 三、Phase 0：素材预处理

### 3.1 切片

把输入切成**素材单元**，不要读成"一篇文章"。单元类型：

- **场景**：某个具体时刻、谁说了什么、在哪里
- **情绪词**：用户自己用的形容词（原文保留，不要换成同义词）
- **判断句**：用户已经下的结论（这些是命题的种子，也是最可能被推翻的）
- **对比**：过去 vs 现在、别人 vs 我、公开说法 vs 私下
- **反例**：用户提到"但也不是所有人都……"的地方
- **数字与时间点**：年份、时长、版本、人数

**每条单元同时打来源标记**：`[我]` 用户自己的材料 / `[他]` 他人文章。
不打标记就直接进 Phase 1，§3.4 的信号规则会被用到错误的对象上（把作者的命题当成用户的命题）。

### 3.2 编号（硬要求：没有编号清单，不许出卡）

切片结果必须先落成编号清单，再进入 Phase 1。这是 §7.1「素材依据」字段唯一合法的引用源。

```
S1 [场景][我] ……（原话）
S2 [语气变化][我] ……（原话，把突然变短/突然玩笑带过的那句单独留出来）
S3 [判断句][他] ……
S4 [未被解释的细节][他] ……
```

**不要跳过这一步直接出卡。** 跳过之后写"素材依据"就是现编一句，
"每张卡必须有素材依据"这条规则会退化成装饰。

### 3.3 三类高价值素材（优先采信）

1. **反复出现的词**。出现两次以上的词，通常是用户真正的题目所在，即使他自己没强调。
2. **语气变化处**。突然变激烈、突然变短、突然开始自我辩解、突然用玩笑带过——这是张力最密的地方。
3. **未被解释的具体细节**。用户写了一个很具体但没说明为什么重要的事（一个机房、一次加班、某个人的一句话）。
   他自己跳过了，说明那里有他没处理的东西。

**这三类是信号，不是结论。** "他没解释"只能推出"此处有未处理的材料"，**不能**推出"他有意回避"。
任何卡片要写"你在回避／你不愿承认"，必须能指出素材里的原话位置（S 几）；
指不出，就降级成"这里有个你没说清的地方"。

### 3.4 素材来源分流（决定这三类信号还成不成立）

上面三类信号默认假设素材是**用户自己**写的。若素材是别人的文章，信号源不同：

| 素材来源 | 可采信的信号 | 不可采信 |
|---|---|---|
| 用户自己的材料 `[我]` | §3.3 三类全部 | — |
| 他人的文章 `[他]` | 作者绕开未解释的细节；被用户收藏/复述的那一句 | 作者的判断句（那是他的命题，不是用户的）；作者的语气变化（那是他的情绪） |
| 混合（自己的 + 他人的） | 按 §3.1 打标后分流：`[我]` 单元跑 §3.3 三类全部，`[他]` 单元只用左列 | 把 `[他]` 单元的信号记在用户名下（最常见的整份"借来的"清单就是这么来的） |

素材里有 `[他]` 单元时，**先问一句，只问这一句**（计入 §十.6 的追问额度，同一额度内不得再问第二次）：

> "这篇里哪句话让你停下来了？"

问完就往下走，不要追问"为什么"。

**用户答不上来时**（"说不上来 / 都差不多"）：不要再问，直接取这两样之一当 `[他]` 单元的替代信号——
他复述过的那句、或转发/收藏时配的那句话；两样都没有，就把 `[他]` 单元整体降权，只按 `[我]` 单元推进。

### 3.5 素材不足时

如果素材全是抽象判断、没有一个具体场景，**先要 2 个具体场景再开工**（计入 §十.6 的追问额度，问完就往下走）：

> "给我一个具体时刻：最近一次让你有这个感觉，是谁说了什么、或你看到了什么？"

因为抽象素材只能产出抽象主题，而抽象主题不能击中。

**额度不够时**：§3.4 已用掉 1 个问题（素材是他人文章时），这里就**只要 1 个场景**即开工，
不要为凑满 2 个而超出 §十.6 的追问额度。

**补完仍然薄时的降级路径**——不要注水，也不要硬撑配额。触发条件是可数的，满足任一即降级：

- 素材单元 < 4 个；或
- 走完 §五 前两步后，**过筛（≥2 个素材单元支撑，或来自语气变化处）的候选 < 7 条**。

降级后按 §7.2 代码块里的「降级态」执行：张数与分组配额同时放宽，**不是只放宽张数**。
清单开头必须写上 §7.2 规定的声明句。
C 组仍然必须有 1 张，从"他写下的那个结论为什么让他自己不安"里取。


### 3.6 起步状态判定（一句话，不向用户宣布）

进 Phase 1 前先判自己拿到的素材属于哪一态，重点过哪批发生器：

- **只有话题（抽象名词域）** → 重点过发生器 1–8
- **有场景、无结论** → 重点过 7（责任错位）、8（命名失效）、10（谁在签字）
- **有明确结论** → 重点过 2（付出vs回报）、9（谁在付钱）、11（被谁教会），
  且必须把结论**翻转**成张力，不许原样复述

### 3.7 用户已经给定题目时

用户不给素材，直接给题目（"我就想写 AI 与学徒制"）：

1. 先按 §3.6 第三种态处理，给 2–3 张从这个题目里翻出来的张力卡试水；
2. 用户仍坚持原题、不想被改成张力 → **不在本 skill 内硬掰**：停下并说清"清单要的是张力，
   题目直接拿去写会空"，然后把话题交回给他，由他决定是补素材还是直接开写；
3. 不要为了守住 §零 的成功标准，把一个用户已经认领的题目改写成他不认识的样子。

### 3.8 中止条件（遇到就停下，不往下跑）

- **用户只提了评价请求、没给素材**（"你觉得我这个题目怎么样"）→ 停下，不启动 Phase 0、不出卡；
  只给 3 条判据式意见（能不能被反对、有没有具体名词、换到别的行业还成立吗），
  并说明"要清单的话，给我素材"。
- **用户要的是初稿或正文** → 停下，说明本流程只产清单、不产正文；问一句"要不要先把方向定下来"。
- **用户素材足够、且已明确说要写哪一条** → 跳过出卡，直接进 §八 收敛。

## 四、Phase 1：张力提取（十一个发生器）

拿每个素材单元过一遍发生器。**命中就记一条，不要筛**——筛选是 Phase 1.5 的事，
在这里做筛选会让发散提前关闭。

1. **期待 vs 现实**：我以为是 A，结果是 B
2. **付出 vs 回报**：我投入最多的那部分，恰好是不再被计价的那部分
3. **公开说法 vs 私下感受**：所有人都说 X，我不敢说的是 Y
4. **手段变目的**：本来用来达成目的的东西，变成了目的本身
5. **时间错位**：我按旧时钟走路，新时钟已经换过了
6. **尺度错位**：个人的具体感受被翻译成宏观趋势，于是无处安放
7. **责任错位**：不是任何人的错，但代价由某个具体的人承担
8. **命名失效**：旧词还在用，但它指的东西已经变了（"成长""熟练""专家"都属此类）

补充发生器（在用户材料偏"理性分析"时特别有效）：

9. **谁在付钱**：这件事的钱从哪来、付给谁、买的是什么
10. **谁在签字**：出了事谁负责；如果没人负责，为什么还能运转
11. **被谁教会**：这项能力的传递路径还在不在

**什么时候停**：每个素材单元都过完 1–8 号发生器（材料偏理性时再过 9–11），
且候选数达到目标卡数的 3 倍（按 §7.2 常态取 8 张，即约 24 条）→ 立即进 Phase 1.5。
继续加发只会让候选池变长，不会让它变好。

## 五、Phase 1.5：筛选（生成与裁决必须分开）

候选池可能是几十条，而卡片只有 7–10 张。**凭什么留？** 按下面的顺序过，
每条候选必须落到某一档，不允许"感觉不错"地留下：

1. **先杀重复**：两条候选如果互换标题仍然成立，合并成一条，保留素材支撑更多的版本。
   不同发生器产出同义张力很常见（1 与 5、3 与 8 经常重合），不合并会让用户觉得你不会数。
2. **按支撑数过门槛，不按支撑数排序**：被 ≥2 个素材单元支撑才准进卡；
   只被 1 个支撑的候选，**只有来自"语气变化处"时才允许进卡**。
   支撑数是含量，不是质量——同一件事说了五遍，不等于张力更强。
3. **排序看两件事**：①这条候选能不能写成一句过得了 §1.4 取反测试的张力；
   ②支撑它的素材**是否彼此不同质**（同质场景重复计数不加权）。
4. **然后按素材实有档位铺分辨率**：先数素材里有几个"可支撑一篇"（宽）、
   几个只够"一次深度探索"（中）、几个"一句话就能钉住"（窄），按实有档位分配。
   底线是 §7.2 的可数要求（常态：两档以上、宽 ≥1、窄 ≥1；降级态：宽或窄占一档）。
   某档素材确实没有就空着，并在组尾分布行注明——**不许为填档现造一条**。
5. **最后定 C 组**：从剩下的候选里挑出"素材里有原话、但用户自己绕开了"的那 1–2 条。
   C 组不参与分辨率配额，也不允许因为它难写就让位——它是整份清单的价值所在。

## 六、Phase 2：命名（决定成败的一步）

> **进入本章前，必须完整读完 `references/naming.md`（七种构造式 + 五条禁令 + 判定走查）。**
> Phase 0–1 期间不要打开它——发散期挂着一堆禁令和构造式，会让人提前自我审查，
> 把候选筛得过分保守。
>
> 把内容挪进 references 只是第一步；走到分岔点必须真的去读，所以这里写成强制动作。

流程：构造式起**标题** → 写卡片的**「张力」行** → 对张力行跑 §1.4 取反测试（判"是不是张力"）
→ 对标题跑 `references/naming.md` 五条禁令（判"是不是这个人的主题"）→ 都过了才进 §七。
标题是框架句，不跑取反测试；张力行是落差，不跑五条禁令。

正文（构造式、构造要求、禁令）只维护在 `references/naming.md`，此处不留副本。

## 七、Phase 3：出卡

### 7.1 卡片格式（严格照写）

```
### {编号} {标题}（{宽/中/窄}｜{A/B/C}）
- **张力**：≤32 字，说清落差。
- **命题**：≤32 字，一句可被反驳的判断。
- **素材依据**：— S4：「素材原话」
- **击中谁**：一个处境限定（如"入职第二年、第一次带人"），不写"很多人"。
- **往下走**：2–3 个短语，不写完整句子。
```

**体量上限**：单卡 ≤6 行；张力与命题各 ≤32 字。
用户的指认带宽比你的生成带宽小得多——长卡会让他在第二张就放弃扫读。

**体量判据不只看数字**：卡内不出现"因为／所以／然而／但是"这类需要第二口气的连接词。
出现就说明你在卡里写论证了，论证属于 §八，不属于卡。

**「击中谁」的写法约束**：若用户就是本人，"击中谁"不许写成人群标签（职场人／技术从业者／年轻人），
必须写成处境限定（"入职第二年、第一次带人""干了三年还在做同一类需求"）。
写不出处境限定，说明这张卡还没落到人身上。

**素材是他人文章时**（§3.4），「击中谁」写**用户与那篇文章的关系处境**
（"读到时正卡在第三年、刚被要求带人"），不写作者的读者群，也不写"很多人"。

### 7.2 配额（护栏，不是规格）

```
常态（默认）：
总数：7–10 张（常态 8–10）。下限防覆盖不足，上限防用户放弃指认。
分组：A 组 3–4 张 ｜ B 组 3–4 张 ｜ C 组 1–2 张（C 组不许为 0）
分辨率：A+B 至少覆盖三档中的两档，且宽 ≥1、窄 ≥1；缺的那档注明，不硬凑。

降级态（触发条件见 §3.5：素材单元 < 4，或过筛候选 < 7 条）：
总数：5–6 张（能出 6 就不出 5，不许拆一条凑两条）
      过筛候选只有 3–4 条时：按实有数出（可低于 5 张），但 A ≥1、B ≥1、C 1 张；
      并在声明句里把实有数写出来（`只支撑到 4 张` 这类），不要凑。
分组：A+B 合计 4–5 张（A ≥2、B ≥2）｜ C 组 1 张（不许为 0）
分辨率：只要求宽 ≥1 或窄 ≥1 至少占一档；中档可缺。
—— 分组配额必须随总数一同放宽，不许出现"总数 5 张、却要求 A3+B3+C1"这种填不上的账。

两种态共用的规矩：
1. 任何偏离都要在清单开头声明。声明句（唯一话术）：
   常态偏离 → `只到 N 张，再多就是注水`
   降级态   → `素材只支撑到这几张，再加就是注水——要不要补两段具体经历？`
   静默越界才算违规（§十.4）；说清了的少发，不算失败。
2. 宁可少发卡，不可发凑数卡。凑数卡一律过不了 §1.4 与五条禁令。

分配顺序（两态通用）：
1. 先定 C 组 1–2 张（降级态 1 张）—— 它最难写，先占位，避免被剩余额度挤成填充物。
2. 再按素材实有档位铺 A+B；某档素材确实没有，允许为 0 并注明。
3. 每组末尾写一行分布：`本组：宽2/中1/窄1`（缺档写 `窄档素材不足，未凑`），让用户看得见。
```

### 7.3 分组（A/B/C，不可合并）

- **A 组 · 正面命中**：素材支撑最充分、我判断最可能击中你的。要有把握，不要划水。
- **B 组 · 侧翼**：你没提但和素材强相关的角度。作用是让你发现"原来我还关心这个"。
- **C 组 · 危险区**：会冒犯你、或揭示你不愿承认的部分。
  必须明确指出**素材里的哪句话**暴露了它。这一组是整份清单的价值所在——
  如果 C 组一张都写不出来，说明只读了字面，没有读人。

**全组的共同边界（不只 C 组）：判断与冒犯都必须落在处境结构上，不许落在人格上。** 可执行判据：

> 任何一张卡都必须能改写成"你的处境里有 X 在起作用"的句式。
> 如果只能改写成"你其实是在 Y"，说明它指向了人格，重写。

C 组在此之上加压：冒犯度 2 格，且必须指明素材原话。

- 不合格：`你其实是在害怕被替代。`
- 合格：`你怕的不是被替代，是你发现没人会为"慢慢变好"这件事付钱。`

### 7.4 出卡时的姿态

- 只给卡，不给建议，不劝进，**不额外排序**。
- 不说"我建议你先看第 3 张"——让用户自己指认。
- **A 组本身即优先级**（最可能击中）。这是判断结果，不是推荐顺序；
  A 在 B 前不等于"A 比 B 好"，它等于"A 离你的素材更近"。
- **不解释"为什么我认为这个好"**——那会把用户的指认变成对我的评价。
  但卡片内的「素材依据」「击中谁」是**证据字段，必须写**：
  区别在于它们指向素材，不指向我的品味。
- 结尾一句话说明怎么用：`勾编号即可，也可以说"3 但方向不对"或"都太抽象"。`

### 7.5 输出形态与分批

- 默认**直接在对话里出清单**，不写文件。用户说"存下来／给我个文件"时才写，
  文件名用被认领的主命题（还没认领就用"素材主题+日期"）。
- 用户说"先给我看两三张"：**按需分批出，配额在末批合并校验**。
  不要以"配额不足"为由拒绝，也不要把剩余额度摊薄成凑数卡。
- 分批时先给 **C 组一张 + A 组一张**——这两张最能判断方向对不对。
  **这是交付节奏，不是推荐顺序**：不许把"A 在前"说成"A 更好"（见 §7.4）。

## 八、Phase 4：勾选之后

用户勾 1–3 个（或说"2 和 5，但我要更窄的"）→ **先查冲突，再收敛**。

**若被勾的几张互相矛盾**（例如一张说"学徒制塌了"、一张说"学徒制从来不存在"），
**先指出它们不能同时成立，并说清冲突在哪一处**，让用户选锚点，再动笔。
不要硬拼成一个内部自相矛盾的主题树。

收敛格式：

```
## 主命题
一句话（从被勾的卡里提炼，可以不同意原卡）

## 为什么值得谈
3 条，每条必须落到编号素材（S3 / S5 / S11）

## 子问题（3–5 个，按回答顺序排）
1. …
2. …
3. …

## 反方最强的一击
这个主命题最可能被怎么反驳（要写得比用户能想到的更强）

## 建议的下一步
- 要写 → 进入写作；把主命题原样传过去，不许改写
- 要谈 → 按下面的子问题顺序逐条展开、逐轮收敛；当前环境有专门的深挖流程就交给它，没有就自己按顺序展开
- 要查 → 指出哪一条需要在现实中验证
```

**不要在这一步扩写正文。** 用户要的是方向，不是初稿；给了初稿他就没得选了。

**交接只在用户明确说"想写／想聊／想查"时发生**；没说就停在主题树上，不主动推进。

**回答"哪个方向最值得写"的合法方式**：不说哪个好，只标出两类信息——
哪几张有素材原话直接支撑（＝最不容易写空的），
哪几张是他素材里自己绕开的（＝最可能有话没说的）。这不是排序，是证据标注。

## 九、Phase 5：不中之后的诊断

用户没认领时，**不要重跑一遍加量**，先诊断是哪一种：

| 用户的原话 | 真实问题 | 处理 |
|---|---|---|
| "都太抽象了 / 太大" | **分辨率错**：给的是中/宽档，他要窄档 | 全部降一档，标题改成一件事的具体时刻 |
| "不是这个感觉" | **情绪未命名**：素材里有情绪词但没被写进卡 | 回到 §3.3 第 2 类，找出语气变化处，重做张力 |
| "对，但这不是我想讨论的" | **手段被当成主题**：他真正关心的在更上游或更下游 | 问一句"你希望讨论完之后，你手上多出什么？"按答案上移或下移一层 |
| "有点像，但不够狠" | 张力成立但**冒犯性不足** | 只改**被勾的那张**及其同组卡：把"不愿承认的部分"往前推一格；不要把所有卡都加辣 |
| **"都还行 / 有几个不错"** | **一张都没击中**，只是不想否定你（不算成功） | 按"情绪未命名"处理：只重做 C 组，全部标题降到窄分辨率。不要原样加量 |
| **只勾一张，不表态** | 已认领，只是不想被追问 | 直接进 Phase 4，主题树只做这一条，不主动延伸 |
| **勾了 2–3 张但互相矛盾** | 撞到两个不同层面的题 | 按 §八 的冲突处理，先让他选锚点 |
| **完全不回应** | 还没认领，也不打算继续 | 止损：不重出卡，只问一句"要窄一点，还是换一批素材？"。问一次不回就停在这里，不再追问 |

**只重跑受影响的组，不要全盘重来**——全盘重来会让用户觉得自己的指认没产生作用。
重出时**不要重复已经出现过的标题**。

**追问上限（全流程唯一口径）**：用户任何一次回复之后，都只许回**一次**追问，
这一次里最多问 2 个问题；问完就按当前信息往下做，不许连环追问。
§3.4 的"哪句话让你停下来"、§3.5 的"给我一个具体时刻"、本节的诊断追问，
共用这一个额度，不各自计一次。

## 十、硬规则（违反任一条即视为本 skill 失败）

1. **不评判用户**：冒犯与判断都指向处境结构，不指向人格或选择（写法见 §7.3）。
2. **不给结论**：不产出"所以你应该……"。
3. **不额外排序、不劝进**：不说"建议你先看第几张"（见 §7.4）。
4. **不静默越界**：张数、体量、分辨率配额是护栏（§7.1 / §7.2）。**偏离必须在清单里声明**；
   静默超量、静默凑数是失败，"少发两张并说明"不是失败。
5. **每张卡必须引用编号素材**：说不出它来自 S 几的卡，删掉（见 §3.2）。
6. **一次追问，最多 2 个问题**：素材追问（§3.4）、场景追问（§3.5）、诊断追问（§九）
   共用同一个额度，问完就按现有信息往下走，不许连环追问。
