# 交付检查

主协调者交付前读取。记录每项已完成、未完成或不适用及原因。未完成必要检查时，说明对交付状态的影响，不机械勾选通过。

- 目标读者、范围、阅读用途和重要推定条件已记录。
- 知识图谱与结构设计可读取；P0、P1 问题有明确归属或排除理由。
- 关键事实与来源可追踪；推断、示例和证据缺口有明确标识。
- 当前章节文件存在、非空、版本正确，内容覆盖实际章节职责。
- 唯一当前状态清单与磁盘版本、原始报告一致；机械检查已运行并记录失败/未检查项，未用机械通过代替内容判断。没有多份需要人工同步的近义状态表。
- 撰写者已自检；未解决问题已交给主协调者。
- 独立评审报告对应当前交付版本，检查范围和状态明确；未独立评审时没有使用“通过独立评审”的说法。
- 修订有快照、问题处理记录和必要复评；达到预算上限的遗留问题已记录。
- 实际修订与问题处理记录可在中断后恢复；派发与失败未虚耗轮次。作者、历史修改者与评审者按实际实体区分，身份或历史未知未被当作通过。
- 跨章术语、假设、示例、数据和结论无未披露冲突；必要的理解回顾已保留。
- 阅读指南、章节链接和本地锚点已核对；外部链接未完成的检查已说明。
- 占位符候选已按语义判断；真实缺口已修复或列为遗留项。
- 整合修改涉及的内容已复核；实质修改未沿用失效的评审状态。
- 连续学习系列已按reader-review完成主路线试读并披露实际覆盖；跳过有原因。读者报告存于工作目录，首次输入未泄漏旧判断；采纳的修改已定向复查，实际问题修订按原预算计数，正常整合另作必要复查。模拟读者意见未声称真实用户验证。
- 最终阅读材料与工作记录分开；旧记录未被覆盖，知识图谱和评审证据默认保留。
- 存在遗留问题时已提供交付状态，聊天中已说明关键限制和入口路径。
