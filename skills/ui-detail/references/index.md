# 反查表：从一句话或一个名词，找到要读的那一篇

> **适用**：症状说不清、只记得一个组件名词，或要确认某篇到底覆盖什么时，用它把词换成文件路径。
> **本轮不可交付时**：若这次任务已经能确定落在某一个阶段（定骨架、写控件、数据与任务、状态、可读可用、交付），停下并说明「已有阶段，不必反查」，直接用 SKILL.md 的阶段表，不要为这一层再花一篇配额。
> **读完能判定**：该读哪一篇、这一篇是否覆盖了你遇到的症状、`references/` 下 25 个文件各自的行数与角色。

按症状说话的人不会用术语。这张表把「按钮跳一下」「下拉点不中」这类原话换成一个文件路径；找不到时按阶段走 SKILL.md 的表，或直接看文末的 25 个文件清单。

**取本文件就算用掉一篇配额**：它替代 SKILL.md 里那两张路由表，不与它们叠加；一次任务仍然只取 2–3 篇。

行数即加载成本：本文件 145 行，阶段篇 64–86 行，详解篇 58–172 行。按这个量级，取本文件 + 2 篇仍然落在预算内；取本文件是为了「症状对不上阶段」的情形，症状能落进阶段时不必取它。
