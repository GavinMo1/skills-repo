# 出卡前自检

> **交付前必须完整读完本文件，逐项过，不跳。** 范围包括：首批清单、分批交付的每一批、
> §九 重出后的每一批。任何一项不过就回改，改完再从头过一遍。
> **Phase 0–1 期间不要打开本文件**：配额与禁令在发散期会触发提前自我审查。
> 主文件 §十一 只留指针，清单正文唯一维护在这里。
>
> 判定分工：**取反测试**判"张力行是不是张力"（主文件 §1.4）；
> **五条禁令**判"标题是不是这个人的主题"（`references/naming.md`）；本文件判"整份清单能不能被指认"。

## 一、逐卡过（九项）

- [ ] 每张卡的「素材依据」都指向真实存在的编号（S1…Sn），不是现编的？
- [ ] 每张卡的**「张力」行**跑过取反测试（主文件 §1.4）？反过来也成立的重写。
      标题**不**跑这一测试，只跑下面的五条禁令。
- [ ] 每张卡的**标题**跑过**五条禁令**（`references/naming.md`）？命中一条就重写。
- [ ] 单卡 ≤6 行、张力与命题各 ≤32 字，且**卡内没有"因为／所以／然而／但是"**？
      出现连接词说明你在卡里写论证，论证属于 Phase 4。
- [ ] 每张卡都能改写成"你的处境里有 X 在起作用"？只能改写成"你其实是在 Y"的，指向了人格，重写。
- [ ] 若卡片写了"你在回避／你不愿承认"，能指出素材里的原话位置（S 几）？
      指不出就按顺序处理：先降级措辞为"这里有个你没说清的地方"，再归入 A 组
      （判别式见主文件 §1.2），不要在 C 组留无出处的卡。
- [ ] 「击中谁」全部是处境限定，没有一个"很多人 / 职场人 / 年轻人"？
- [ ] 素材含他人文章时，「击中谁」写的是**用户与那篇文章的关系处境**，不是作者的读者群？
- [ ] 卡片里没有出现用户的判断句原样复述（`[他]` 单元的命题被当成用户的）？

## 二、整份清单过（七项）

- [ ] C 组 ≥1 张，且每张都指出了素材里的哪句话暴露了它？
- [ ] 冒犯度按组分档（A 组至少一半 1 格、B 组 0 格、C 组每张 2 格），不是每张都在刺人？
- [ ] 张数与分组是否自洽？**常态**：7–10 张、A3–4/B3–4/C1–2；
      **降级态**（主文件 §3.5）：5–6 张、A+B 合计 4–5（各 ≥2）、C 1 张；
      过筛候选只有 3–4 条时：按实有数出，A ≥1、B ≥1、C 1 张。
      不许出现"总数 5 张却要求 A3+B3+C1"。
- [ ] **任何偏离都没有静默发生**——清单开头有一行声明（话术见主文件 §7.2）？
- [ ] 分辨率覆盖达标（常态：至少两档且有宽 ≥1、窄 ≥1；降级态：宽或窄至少占一档）；
      组尾标了分布；缺档写的是"素材不足，未凑"而不是硬凑一张？
- [ ] 通篇没有建议、没有排序、没有"我觉得这张最好"？
- [ ] 结尾有那句用法说明（`勾编号即可，也可以说"3 但方向不对"或"都太抽象"。`）？

## 三、用户回复到手时（不算出卡，但没有这一条整份清单等于没做完）

- [ ] 用户的回复落在主文件 §1.3 的反向信号里（"说得挺对／很深刻／有意思／我也想这么说"）？
      是 → 按 §九 当"没认领"处理，**不得**当作勾选、不得进 Phase 4。
