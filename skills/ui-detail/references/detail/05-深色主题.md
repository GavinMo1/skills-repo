# 05 · 深色主题：重新安排表面与强调

> **适用**：新做或改造深色模式：白底换黑底后卡片边界消失、按钮刺眼、截图变灯箱，或要接「跟随系统/浅色/深色」三档与首屏防闪白时。
> **不适用**：只是核某个色值过不过 AA、要算对比度（04），或只查深色下浮层的开合定位与动画（01、12）时。
> **读完能判定**：这个界面需要哪几层表面、深浅两侧的抬升方向怎么走；该不该用纯黑纯白；深色浮层靠表面差、描边、遮罩还是阴影交代边界；品牌色是否按职责拆成不同值；图片该不该统一调亮度；三档偏好怎么存、首屏怎么早应用、SSR 下初始主题怎么对齐。

把项目页的白底换成黑底后，卡片边界不见了，蓝色按钮显得刺眼，上传截图却像一块灯。问题来自不同内容的亮度关系，单纯反色无法保留这些关系。

## 先决定有哪些表面

页面背景、卡片、浮层、选中区域需要能被辨认。深色界面常用逐层变亮的表面辅助表达层级；浅色界面则可能多个表面都用白色，通过边界和阴影区分，并不存在“抬升必须变暗”的统一规则。

| 语义 | 浅色起点 | 深色起点 |
|---|---|---|
| 页面背景 | `#F6F7F9` | `#121212` |
| 卡片/浮层表面 | `#FFFFFF` | `#1F1F1F` |
| 主文字 | `#1F1F1F` | `#E0E0E0` |
| 次文字 | `#595959` | `#B0B0B0` |
| 装饰分隔线 | `#E2E2E2` | `#3F3F3F` |

这是项目示例，不代表某个设计系统的当前默认值。装饰分隔线不能直接拿去承担输入框识别、选中标记等必要信息，后者需要另行检查对比度。

## 纯黑、纯白都需要看用途

纯黑可用于 OLED、媒体浏览或产品特定风格；采用近黑则更方便用亮度划分多个表面。两者都有成立场景。“OLED 会不会拖影”还与面板和刷新行为有关，不能作为一律禁用纯黑的理由。

纯白文字在某些暗环境中会让人感觉刺眼或有光晕，降低前景亮度可能改善舒适度，但不能把文字调到不达标。字体、字号、显示器、环境与用户视觉状况都会影响体验。

屏幕在明暗主题下都在发光。“浅色像纸、深色像暗场”可以帮助理解视觉风格，不能当作两种真实物理模型，更不能据此推导通用的字号或字重补偿。

## 浮层用多种线索表达边界

阴影在暗底上通常更难辨认，可以联合表面差、描边和遮罩。阴影仍可能有用，没必要一律加倍透明度，也没有“所有深色浮层必须加 1px 亮边”的统一要求。

Tooltip 与 Toast 可以用浅底深字制造对比，也可以沿用深色表面。要检查它们与周围区域能否区分，以及文本本身是否清楚。需要关注的错误最好靠位置、图标和明确文案表达，别只指望突然反色。

模态遮罩的目标是降低背景干扰，并配合真实的背景交互阻断。应在复杂页面上观察效果，`.6` 只是一个可能起点。

## 品牌色与图片要分别处理

按钮背景上的文字、文字链接、轻色容器里的强调色，承担不同职责，不能共用一个“品牌蓝”。深色主题的链接可能需要更亮，填充按钮则要同时检查按钮文字与背景的组合。

不要给所有图片统一加 `brightness(.85)`：这会改变照片、图表和截图的事实呈现。可针对插画提供主题版本，给透明 Logo 换适合的资源，为亮截图加容器边界。媒体查看场景一般应保留原图显示方式。

## 系统偏好与手动选择

```css
:root { color-scheme: light; }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) { color-scheme: dark; }
}
:root[data-theme="light"] { color-scheme: light; }
:root[data-theme="dark"] { color-scheme: dark; }
```

这里仅演示原生控件的配色声明，自定义颜色还要按相同选择规则映射 Token。`color-scheme` 不会替你把自定义卡片和文字改色。

提供“跟随系统 / 浅色 / 深色”三种选择，保存用户显式偏好。首屏尽早应用主题，避免先白后黑；有服务端渲染时，还要处理服务端与客户端初始主题一致性。

用同一条路径验收两次：进入列表、打开详情、展开菜单、触发错误、禁用按钮、查看截图。还要检查原生输入控件、滚动条和系统强制颜色模式。

参考：[MDN color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/color-scheme)、[MDN prefers-color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-color-scheme)、[Material 颜色角色](https://m3.material.io/styles/color/roles)。
